# Fermes Dubois et fils

Site web satirique de sensibilisation — **viandes canines biologiques**.

Basé sur le contenu de Ferme Gagnon (Railway) et inspiré d’Elwood Dog / ferme-bernier, rebrandé **Fermes Dubois et fils**.

## Stack

- React 19 + Vite 7 + Tailwind 4 + Wouter
- FR / EN i18n
- Deploy: Railway (`pnpm build` → `pnpm start`)

## Local

```bash
pnpm install
pnpm dev
```

## Production

```bash
pnpm install
pnpm build
pnpm start
```

## Contenu

Pages: Accueil, Races, Recettes, Blogue, FAQ, Ressources, Boutique, La Ferme, Contact.

Logo: `public/logo.png` (Fermes Dubois et fils — viandes canines biologiques).
